# Lizwi — releases

Builds of the **Lizwi** Android app, published here so anyone can download
them. Lizwi puts the verse a preacher is on onto every phone in the room,
and reads the Bible offline when there is no signal at all.

**Download the latest version:** https://lizwiapp.co.za

This repository holds the built app and nothing else — no source code.

## Verifying a download

Every release is signed with the same key. If a build is genuinely ours its
certificate fingerprint reads:

```
SHA-256: c3c0a6c60727377551be886035e09f3b9a18e934ce60e917f8f08531c4efbc88
CN=Lungelo Ngcemu, O=lizwiapp, L=Durban, C=ZA
```

An APK from anywhere else, or one that does not match, is not ours.

## Installing

Android asks you to allow installs from your browser the first time. That
warning is normal for an app that does not come from the Play Store — it is
telling you the truth, that this came from us rather than from Google.

A new version installs over the old one and keeps every sermon.
